# Test And Audit Outputs

This directory stores generated or snapshot-style outputs from validation,
audit, and experiment runs. Treat it as artifact evidence, not the primary
documentation home.

Current maintained docs are indexed from [`../docs/README.md`](../docs/README.md).

Tracked markdown files here are usually narrow validation records, such as
`htf_test_script_validation_20260429.md`. New large generated outputs should
remain ignored unless they are intentionally added as lightweight review
evidence.
