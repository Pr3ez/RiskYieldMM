# Regression Feature Reports

## Purpose

This directory is reserved for small, curated report templates or tracked
summaries. Large generated audit outputs should stay under ignored `test_output/`
paths.

## Current Status

No reports are generated by the scaffold.

## Scope

Future reports should summarize `regression_path_features_v1` quality,
zero-target validation, feature-family usefulness, and walk-forward comparison
against HTF-only baselines.

## Source Of Truth

Use `regression_feature_engineering/docs/documentation_index.md` before adding
new report types.

## What This Does Not Decide

This directory does not define feature formulas or training policy.
