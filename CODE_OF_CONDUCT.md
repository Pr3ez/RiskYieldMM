# Code of Conduct

## Purpose

RiskYieldMM is a technical research project. Contributions and discussions should
stay clear, evidence-based, and respectful so that difficult ML, data, and
trading-system questions can be reviewed without personal friction.

## Expected Behavior

- Be respectful and direct. Critique code, data, methods, and assumptions rather
  than people.
- Keep claims grounded in reproducible evidence: commands, artifacts, metrics,
  plots, logs, or source references.
- Be careful with financial-language claims. This repository is research
  software, not trading advice or a live trading service.
- Respect privacy. Do not publish private credentials, API keys, personal
  documents, proprietary datasets, or sensitive market-data access details.
- Prefer transparent disagreement. If a result appears wrong, explain the
  suspected failure mode and provide enough context for others to reproduce it.

## Unacceptable Behavior

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing private information without explicit permission.
- Intentionally misleading performance, risk, or reproducibility claims.
- Submitting generated data, model artifacts, or credentials that should remain
  local/private.
- Repeatedly ignoring maintainer requests around scope, safety, or evidence.

## Enforcement

Maintainers may edit, hide, or remove issues, pull requests, comments, or
contributions that violate this code. Repeated or severe violations may result in
temporary or permanent loss of participation privileges.

If you need to report a conduct issue, contact the project maintainer through
GitHub. For security-sensitive reports, follow `SECURITY.md` instead of opening a
public issue with sensitive details.
