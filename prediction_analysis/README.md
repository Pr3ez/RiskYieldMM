# Prediction Analysis Reports

This directory contains historical research outputs, comparison reports, and
run-specific analysis artifacts. Keep these reports near their originating run
folders so the artifact context stays intact.

For maintained design documentation, start at [`../docs/README.md`](../docs/README.md).

## Layout

| Location | Contents |
|---|---|
| [`reports/`](reports/) | Historical comparison and dependency reports |
| [`research_outputs/`](research_outputs/) | Dated research summaries and recommendations |
| [`one_minute_target4class_pattern_outputs/`](one_minute_target4class_pattern_outputs/) | One-minute target/pattern analysis outputs |
| [`multitimeframe_cross_target_validation/`](multitimeframe_cross_target_validation/) | Multitimeframe cross-target validation audits |

Root-level markdown files in this directory are dated research notes retained
with the prediction-analysis output set.
